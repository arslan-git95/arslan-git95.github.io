# Arslan Hanif | Portfolio website

A fast, static, one page portfolio. No build step, no frameworks.

## Publish on GitHub Pages (free)

1. Sign in at github.com and click **New repository**.
2. Name it `YOUR-USERNAME.github.io` (replace with your GitHub username), set it to **Public**, and create it.
3. Click **Add file, then Upload files**, drag in everything from this folder (index.html, the assets folder, 404.html, robots.txt, .nojekyll, README.md), and click **Commit changes**.
4. Open **Settings, then Pages**. Under **Build and deployment**, choose **Deploy from a branch**, pick the `main` branch and the `/ (root)` folder, and save.
5. Wait about a minute. Your site is live at `https://YOUR-USERNAME.github.io`.

## Edit later
Change text in `index.html` and commit. Images are in `assets/`.
